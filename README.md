# PED · Exam 3 Study Desk

Interactive pediatrics study guide with a black-and-white 90s desktop aesthetic.

**Live site:** https://george1912.github.io/ped-fun-page/

## Develop

```bash
npm install
npm run dev
```

## Deploy

Pushes to `main` build and publish automatically via GitHub Pages (Actions).
You can also re-run the **Deploy to GitHub Pages** workflow manually from the Actions tab.
